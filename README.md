# Online Quiz Application

## 📌 Project Overview

The **Online Quiz Application** is a simple and interactive web-based quiz system developed using **HTML, CSS, and JavaScript**. It allows users to answer multiple-choice questions within a limited time and automatically calculates their final score.

## 🎯 Features

* User-friendly quiz interface
* Multiple-choice questions
* 30-second timer for each question
* Automatic score calculation
* Instant result display
* Restart quiz option
* Responsive design
* Simple and attractive interface

## 🛠️ Technologies Used

* **HTML5** – Creates the structure of the website
* **CSS3** – Provides styling and responsive design
* **JavaScript** – Handles quiz logic, timer, answers, and score calculation

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder in **Visual Studio Code**.
3. Open `index.html`.
4. Run the file using a web browser.
5. Click **Start Quiz**.
6. Answer the questions before the timer ends.
7. View your final score.

## 🎮 How It Works

1. The user starts the quiz.
2. A question with four options is displayed.
3. The user selects an answer.
4. Each question has a **30-second time limit**.
5. The application checks the selected answer.
6. The score is calculated automatically.
7. The final result is displayed after all questions are completed.
8. The user can restart the quiz.
